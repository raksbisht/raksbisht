## 🧩 Cursor plugins

| Plugin | What it does | Links |
|---|---|---|
| **Dead Code Finder** | Finds unused imports, functions, exports and unreachable code — in any language | [Repo](https://github.com/raksbisht/dead-code-finder) · [Install](https://cursor.directory/plugins/dead-code-finder-2) |

## ⌨️ Git CLI tools

| Tool | What it does | Try it |
|---|---|---|
| **[morning-git](https://github.com/raksbisht/morning-git)** | "What did I do yesterday?" — your last working day's commits, grouped by repo. Standup-ready. | `npx morning-git` |
| **[git-receipt](https://github.com/raksbisht/git-receipt)** | Prints your git activity as a thermal receipt, tech-debt tax included 🧾 | `npx git-receipt` |
| **[secret-history](https://github.com/raksbisht/secret-history)** | Finds secrets that were committed and "deleted" but still live in git history | `npx secret-history` |
| **[blame-yourself](https://github.com/raksbisht/blame-yourself)** | Your authorship stats across an entire repo | `npx blame-yourself` |
